基本概念：
temperature(温度/性格)：是一个 0-2 的浮点数：
数值越大，代表生成的内容更加随机，更有创造性————代表激进
数值越小，代表生成的内容更加集中，有规律————————代表保守

| 应用场景 | 推荐 Temperature | 说明 |
| :--- | :--- | :--- |
| 代码生成 / 补全 | 0.0 ~ 0.2 | 代码需要精确语法，几乎不允许随机性 |
| 数据提取 / JSON格式化 | 0.0 ~ 0.1 | 结构化输出必须严格遵循格式，避免字段错乱 |
| 数学推理 / 逻辑分析 | 0.0 ~ 0.3 | 推理链需要确定性，高温度会导致步骤跳跃 |
| RAG / 知识问答 | 0.1 ~ 0.3 | 基于检索内容回答，需忠实于原文，抑制幻觉 |
| 通用对话 / 客服 | 0.5 ~ 0.7 | 平衡准确性与自然度，避免机械感 |
| 文案创作 / 营销内容 | 0.7 ~ 1.0 | 需要语言多样性和创意表达 |
| 头脑风暴 / 创意写作 | 1.0 ~ 1.5 | 最大化发散思维，探索非常规想法 |
| 诗歌 / 小说 / 角色扮演 | 1.0 ~ 1.5+ | 鼓励风格化表达和非线性叙事 |


maxTokens（平时用到这个参数的场景不多！）
用来限制 AI模型生成的最大token数，可以理解为字数上限。
- 需要简洁回复、打分、列表、摘要等，建议用比较小的值，比如：10--50。
- 防止用户跑长会话导致无关内容花费过多的token费用。
- 如果遇到生成内容被截断，可以适当调大 maxTokens。
